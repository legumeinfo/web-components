<lis-histogram-element>

The <lis-histogram-element> is a "dumb" vizualization component for drawing a histogram. It doesn't fetch or bin data itself; it only draws whatever pre-binned data is given to it via its data property, e.g. as produced by D3's own bin generator.

Optional xLabel, yLabel, and height attributes/properties control the axis labels and the height of the chart area. The width will always fill to the parent element.
