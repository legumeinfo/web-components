<lis-retrieve-one-gene-sequence-element>

Component 1 of the retrieve-sequence spec: fetch protein / CDS / genomic sequence for a single gene by ID. The element talks to three backends:

  • dscensor resolves the gene's annotation prefix to its canonical file URLs.
  • graphql-server (required) resolves the gene's longest mRNA + chromosome coordinates in one small POST query. There is no fallback: if GraphQL doesn't know the gene, the retrieve fails with a clear message and the user picks a different gene.
  • ds_utilities handles the FASTA slicing for the sequences themselves (protein, CDS, genome with optional flank).
