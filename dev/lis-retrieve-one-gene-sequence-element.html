<lis-retrieve-one-gene-sequence-element>

Component 1 of the retrieve-sequence spec: fetch protein / CDS / genomic sequence for a single gene by ID. The element talks to up to three backends:

  • dscensor resolves the gene's annotation prefix to its canonical file URLs.
  • graphql-server (preferred path when set) resolves the gene's longest mRNA + coordinates in a single small query, avoiding a multi-MB BED download per search.
  • ds_utilities reads the BED (only when GraphQL doesn't know the gene) and always handles the FASTA slicing for the sequences themselves.
